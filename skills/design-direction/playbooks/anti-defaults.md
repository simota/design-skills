# Anti-Defaults

Generic output is not a taste failure; it is a *decision* failure. Every unmade decision falls back to a default, and the defaults are all the same.

## The default look

If output drifts here without an argument, stop and re-decide:

- Inter (or system-ui) at every size, one weight for headings, one for body
- A violet→blue gradient carrying the brand
- Uniform cards: white surface, 8–12px radius, soft shadow, 24px padding
- Everything centred, max-width ~1200px, three-column feature grid
- Emoji as icons
- Rounded-full pill buttons on every action
- Section rhythm of hero → three cards → testimonial → CTA
- No texture, no edge, no asymmetry, no restraint list

None of these is wrong. All of them chosen together, without reasons, is the tell.

## Distinctness checks

Run these before presenting a direction.

| Check | Question | Fail signal |
|-------|----------|-------------|
| Substitution | Rewrite the one-line thesis with a named competitor substituted — does it still read true? | It still reads true |
| Reason audit | Can you state a reason for the typeface, the accent, the radius, the density? | Any "it looked good" |
| Restraint | What does this direction refuse? | The list is empty |
| Memory | Write the one-sentence description, then list which of the three considered directions it could equally describe | More than zero |
| Layer coverage | Are all six direction layers decided? | Surface or Restraint is blank |

## Sources of distinctness

Reach for these before reaching for a louder colour.

| Lever | Moves |
|-------|-------|
| Density | A deliberately dense tool reads as expert; deliberate space reads as calm |
| Type contrast | Large display-to-body ratio, or an unusual pairing, changes character instantly |
| Edge language | Hairline borders vs shadows vs flat fills is a whole personality |
| Corner discipline | One radius everywhere, or radius reserved for one element class |
| Alignment | Consistent asymmetry (left-weighted, offset grids) against the centred default |
| Neutral temperature | Warm paper vs cool glass changes everything before any accent appears |
| Restraint | Removing a category of decoration entirely is a stronger signal than adding one |

## When the default is correct

Sometimes it is. Enterprise integrations, internal tools inheriting a platform's conventions, and products whose users expect a familiar shell are all served by convention. If so, say it in the brief as a decision: "Convention-led: this surface adopts platform defaults so it disappears into the host product." A stated default is a direction. An unstated one is drift.
